# new2D3D

VTuberアセットエンジン(事前生成した静的アセット+実行時はLLM推論のみで
状態遷移を決める軽量キャラクター駆動エンジン)の検討・実装リポジトリ。

## 経緯

[`amanesf/ghostitd`](https://github.com/amanesf/ghostitd)で動画→3D化
(visual hull)に取り組んでいたところ、ツインテールのような細長いパーツが
理論上細り続けるという手法自体の限界に突き当たった。この発見を受けて
代替アーキテクチャ(パーツ×角度×表情の静的アセットをオフライン生成し、
実行時はテキストLLMで画像IDを選ぶだけにする方式)を検討したのが
[`VTUBER_ASSET_ENGINE_PLAN.md`](./VTUBER_ASSET_ENGINE_PLAN.md)。以後の
検討・実装はこのリポジトリで継続する。

`ghostitd`側の3Dtool(動画→3D化のコードベース)は参照元として残っており、
本計画書内の相互参照(例: パーツのタクソノミー設計における
`js/accessories.js`)は`ghostitd`側のファイルを指す。

引き継ぎ」参照)。
