# イラスト1枚→スーパーLive2D(ベクターパペット)化ワークフロー(2026-07-19)

> `SUPER_LIVE2D_MOBILE_METHOD.md`の手法を「実在の立ち絵」に適用する手順の
> 整理。**正面立ち絵1枚だけを入力**とし、外部AI・GPU・画像素材を使わずに
> 全周回転+表情差分を持つパペットを作る。本ワークフローは金髪ツインテール
> のキャラクター(黒チェックのオフショルニット+赤マフラー+緑プリーツ
> スカート+ニーソ+編み上げブーツ)で実際に一巡し、
> [`characters/blonde_twintails.html`](./characters/blonde_twintails.html)
> として検証済み。

## 0. 入力と前提

- **必須**: 正面の全身立ち絵1枚(Tポーズでなくてよい)
- **任意**: 横・背面の絵。あれば**検証用の正解データ**として使うだけで、
  製作自体には使わない(理由は§3)
- 原画ファイルの置き場所は `characters/ref/`。
  **チャットに貼られた画像はサンドボックスにファイルとして保存されない**
  ため、原画をリポジトリに含めたい場合はユーザーがGitHub(スマホの
  ブラウザ/アプリ)から `characters/ref/` に直接アップロードする。
  Claudeは会話中の画像を「見る」ことはできるので、製作・照合はファイル化
  されていなくても可能(今回はその方法で実施)。

## 2. 採寸と配色

- **単位は頭部半径r**。正面画像から頭身(今回≒6頭身)と各部の縦横比を
  読み、r=40pxとしてキャラ空間座標(原点=首の付け根、+y上)に落とす。
- **パレットは目視サンプリング**で16色程度に量子化(肌・肌影・髪・髪影・
  髪ハイライト・虹彩2段・服・柄線・小物色…)。原画がファイルとして
  あればスクリプトでピクセル実測に置き換えられる。

## 3. 奥行き(z)の補完規則 — 「正面1枚で足りる」根拠

正面画像にはx・yしか無いが、プリミティブの構造がzを規定する:

1. **card**: 頭球面に貼るので、正面のxy位置から球面上の(方位角, 仰角)が
   一意に決まる。回転時の挙動(滑走・cos縮小・カリング)は球が与える。
2. **ribbon**: チューブ半径=正面で見える幅の半分。スパインのzは既定則で
   与える(髪は頭球の接線から後方へ逃がす、マフラー前垂れは体の前面+z、
   後ろ垂れは背面−z、など)。画面空間で幅を付けるため、zの多少の誤差は
   見た目に影響しにくい。
3. **volume**: 左右対称+標準の厚み比(体の奥行き=幅の6割前後)で補完。
   見かけ幅は `1 − k·|sin(体yaw)|` で近似する。
4. **体の遅れ回転(ラグ方式)**: `体yaw = yaw − lag·sin(yaw)`
   (今回 体lag=38°、脚lag=55°)。小角度では首だけ先に回る自然な視差、
   180°では完全に追いつくので背面も破綻しない。
   ※一定比率(体yaw=0.55·yaw)は背面で腕・体の向きが破綻する
   (実測済みの失敗)。ラグ方式が正解。
5. **Z順**: 全パーツの深度ソートで自動。角度別メタデータ不要。

横・背面の原画は、この補完結果の答え合わせにだけ使う(今回は
マフラー垂れが「横から見ると背中側」であることの確認に効いた)。

## 4. コード化 → Claude視覚フィードバックループ

1. パーツをコード化(PoC `poc/vector_puppet_poc.html`のエンジン構成を流用)
2. ヘッドレスChromium(Playwright)でyaw 0/45/90/135/180+表情を撮影
3. Claudeがスクリーンショットと原画(会話中の画像)を見比べ、齟齬を列挙
4. コード修正 → 再撮影。**修正は決定的で、直した箇所以外は変わらない**

今回の収束実績: **3イテレーション**。発見・修正した齟齬:

| # | 齟齬 | 修正 |
|---|---|---|
| 1 | ツインテールが太すぎ・直線的で腕を覆う | 幅プロファイル縮小、ハの字の外流れ+毛先ウェーブに変更 |
| 2 | マフラーの輪が顎に重なり、前垂れが太く中央すぎ | 輪を下げ縮小、前垂れを細く左側へ |
| 3 | 目・口が高すぎる(アニメ顔は中心より下) | 目を仰角−8°、口を−38°へ |
| 4 | オフショルの素肌の肩がニットに隠れる | 襟ぐりを肩線より深く |
| 5 | 背面で腕が背中中央に黒い帯として出る | 体の回転をラグ方式に刷新(§3-4) |
| 6 | 真横でマフラー前垂れが顔前に垂れる(原画では背中側) | \|yaw\|>70°でフェードアウト |
